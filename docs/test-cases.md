# Тест-кейсы

| Атрибут | Значение |
|---|---|
| Объект тестирования | Conduit (RealWorld) — платформа публикации статей |
| Уровень тестирования | API |
| Источник требований | [Спецификация эндпоинтов RealWorld](https://realworld-docs.netlify.app/docs/specs/backend-specs/endpoints) |
| Окружение | `https://node-express-conduit.appspot.com/api` |
| Аутентификация | JWT, заголовок `Authorization: Token {jwt}` |
| Тестировщик | Власенко Д. Р. |
| Обновлено | 18.09.2026 |

**О кодах ответа.** Публичные развёртывания Conduit возвращают разные коды для одной ошибочной ситуации. В ожидаемых результатах негативных тест-кейсов указан допустимый набор кодов; на развёртывании с фиксированным контрактом указывается одно значение.

## ТК-01

| Атрибут | Значение |
|---|---|
| **Заглавие** | Регистрация пользователя с валидными данными |
| **Приоритет** | Критический |
| **Требование** | `POST /users` — Registration |
| **Модуль / подмодуль** | Аутентификация / Регистрация |

**Исходные данные**

Отсутствует пользователь с указанным адресом электронной почты и именем.

| Шаги | Ожидаемые результаты |
|---|---|
| 1. Отправить `POST /users` с телом, содержащим уникальные `email`, `username`, `password` | 1. Код ответа 200 или 201. Поле `user.email` равно переданному, `user.username` равен переданному, поле `user.token` не пустое |

**Автотест:** `AuthTests.registersNewUser`
